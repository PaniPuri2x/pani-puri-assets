PANI PURI 2X — RUST SIGN ARTIST PROMOTIONAL IMAGE PACK
==================================================

38 individual promotional images. No DRACO text.
Each filename identifies the Rust sign/frame type. Images are exact-size, optimized PNGs.

INSTALLATION
1. Upload each desired PNG to the public GitHub repository PaniPuri2x/pani-puri-assets on the sil-artist branch.
2. Click the file on GitHub, choose Raw, and copy its raw.githubusercontent.com URL.
3. In Rust, aim at the deployed sign or frame and type: /sil <DIRECT_IMAGE_URL>
4. If the URL produces a missing Content-Length error, use an image host/CDN that supplies a Content-Length header.
5. Sign Artist default maximum file size is typically 1MB; all images in this pack were optimized below 850KB.
6. For two-sided signs, you may need to paint each side separately.
7. Some newer DLC frames may require a current Sign Artist plugin with prefab mappings.

IMPORTANT: Feature-related art is promotional. Confirm each feature is live before advertising it as available.
Rust / Sign Artist image-size mappings can differ by plugin version; use the dimensions shown as source files.
