PANI PURI 2X - short URL neon animation frames

1. Open https://github.com/PaniPuri2x/pani-puri-assets
2. Select main branch, Add file > Upload files. Upload n1.png through n5.png to the ROOT (not a folder). Commit changes.
3. Check each raw URL in a browser (must show image, not 404).
4. Aim at your ANIMATED NEON SIGN and run one chat command for each frame:

/sil 1 https://raw.githubusercontent.com/PaniPuri2x/pani-puri-assets/main/n1.png
/sil 2 https://raw.githubusercontent.com/PaniPuri2x/pani-puri-assets/main/n2.png
/sil 3 https://raw.githubusercontent.com/PaniPuri2x/pani-puri-assets/main/n3.png
/sil 4 https://raw.githubusercontent.com/PaniPuri2x/pani-puri-assets/main/n4.png
/sil 5 https://raw.githubusercontent.com/PaniPuri2x/pani-puri-assets/main/n5.png

If files are uploaded to sil-artist branch instead, replace /main/ with /sil-artist/ in the URLs.
The image filenames and case must match exactly. These are static PNG frames for a 5-frame neon sign, not a GIF.
